## Key Features

1. **Real-Time Facial Emotion Detection** – Identifies facial expressions such as happy, sad, angry, neutral, fear, surprise and disgust.
2. **Live Webcam Detection** – Uses a webcam to capture live video for recognition.
3. **Hand Sign Recognition** – Detects and recognizes supported basic hand gestures.
4. **Interactive Web Interface** – Provides a user-friendly interface to access the recognition features.
5. **Instant Recognition Results** – Displays detected emotions and recognized hand signs.
6. **Combined Recognition System** – Integrates facial emotion recognition and hand gesture recognition into one application.

## Project Objective

The main objective of EMOZ is to develop an integrated computer vision system that can recognize facial emotions and basic hand gestures in real time using a webcam.
